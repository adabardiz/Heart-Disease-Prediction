# Heart-Disease-Prediction

Welcome to my heart disease prediction project! I put this together to learn more about machine learning in general.

This project uses a dataset that consists of 303 patients. It looks at 14 different factors like age, resting blood pressure, cholesterol and chest pain type to determine whether a patient is at risk for heart disease.

I used a standart Python data science stack:

- Pandas & NumPy for data wrangling
- Matplotlib & seaborn for the visualisations
- And Scikitlearn for machine learning.

Feel free to poke around the notebook & look at the code!
